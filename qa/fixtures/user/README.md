# User-provided samples

Place only approved, redacted real-world documents here for local QA. Round 3
currently uses 12 private fixtures across PDF, Word, Excel, and PowerPoint.

The files must not contain secrets or personal data that should be published.
They stay local and are ignored by Git. Record their identity only in an
ignored local manifest, use anonymous case IDs in publishable evidence, and do
not commit filenames, hashes, paths, or document contents.
